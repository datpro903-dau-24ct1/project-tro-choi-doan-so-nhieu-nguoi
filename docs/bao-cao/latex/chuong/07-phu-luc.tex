\section*{A. Hướng dẫn cài đặt và chạy chương trình}
\phantomsection
\addcontentsline{toc}{section}{A. Hướng dẫn cài đặt và chạy chương trình}

Các bước chuẩn mực để khởi chạy hệ thống trên bất kỳ máy tính nào cài đặt JDK 21:

\begin{lstlisting}[language=bash, caption={Các lệnh PowerShell biên dịch và khởi chạy hệ thống.}]
# 1. Change directory to the project root
cd "project-tro-choi-doan-so-nhieu-nguoi"

# 2. Compile all source and test files with UTF-8 encoding
$files = Get-ChildItem -Recurse -Filter *.java -Path src, test | Select-Object -ExpandProperty FullName
javac -encoding UTF-8 -cp "lib/*" -d bin $files

# 3. Execute all 103 automated JUnit 5 test cases
java -jar lib/junit-platform-console-standalone.jar execute --class-path bin --scan-class-path

# 4. Start the GameServer (listening on default port 8888)
java -cp bin doanso.net.GameServer

# 5. Launch the Swing ClientUI (can open multiple windows to play concurrently)
java -cp bin doanso.ui.ClientUI
\end{lstlisting}

\section*{B. Bảng tự kiểm trước khi nộp}
\phantomsection
\addcontentsline{toc}{section}{B. Bảng tự kiểm trước khi nộp}

Trước khi nộp bài tập lớn, nhóm đã tự rà soát và đánh dấu kiểm tra đầy đủ:

\begin{tukiem}
  \item Sản phẩm chạy được trên máy tính khác độc lập, không phụ thuộc vào đường dẫn tuyệt đối của máy cá nhân.
  \item Đã chạy thử nghiệm thực tế và toàn bộ 103 bài test tự động JUnit 5 đều đạt 100\% xanh.
  \item Toàn bộ mã nguồn được lưu trữ trên kho GitHub, lịch sử commit minh chứng tiến độ đều đặn qua các nhánh tính năng.
  \item Mọi sơ đồ kiến trúc, bảng biểu và khối mã nguồn đều có tiêu đề, nhãn số và được giải thích rõ trong thân bài.
  \item Khai báo minh bạch việc sử dụng công cụ AI hỗ trợ theo đúng quy định liêm chính học thuật.
  \item Đã rà soát và xóa bỏ toàn bộ các hộp gợi ý, các khối văn bản mẫu.
\end{tukiem}
