\section*{A. Hướng dẫn cài đặt và chạy chương trình}
\phantomsection
\addcontentsline{toc}{section}{A. Hướng dẫn cài đặt và chạy chương trình}

Các bước dưới đây cho phép biên dịch, chạy toàn bộ 103 ca kiểm thử tự động và
khởi chạy trực tiếp máy chủ cùng nhiều cửa sổ máy khách trên mọi máy tính đã
cài đặt JDK 21.

\begin{lstlisting}[language=bash, caption={Các bước biên dịch, chạy kiểm thử JUnit 5 và khởi chạy ứng dụng.}]
# 1. Clone the repository
git clone https://github.com/datpro903-dau-24ct1/project-tro-choi-doan-so-nhieu-nguoi.git
cd project-tro-choi-doan-so-nhieu-nguoi

# 2. Compile all source and test files using UTF-8 encoding (PowerShell)
$files = (Get-ChildItem -Path src,test -Recurse -Filter *.java).FullName
javac -encoding UTF-8 -d bin -cp "lib/junit-platform-console-standalone.jar;src;test" $files

# 3. Execute all 103 JUnit 5 automated tests
java -jar lib/junit-platform-console-standalone.jar execute --class-path bin --scan-class-path

# 4. Launch two Swing client windows and start the TCP GameServer on port 8888
Start-Process java -ArgumentList "-cp bin doanso.ui.ClientUI"
Start-Process java -ArgumentList "-cp bin doanso.ui.ClientUI"
java -cp bin doanso.net.GameServer
\end{lstlisting}

\section*{B. Bảng tự kiểm trước khi nộp}
\phantomsection
\addcontentsline{toc}{section}{B. Bảng tự kiểm trước khi nộp}

Nhóm đã rà soát toàn bộ các tiêu chí đánh giá học phần trước khi nộp báo cáo:

\begin{tukiem}
  \item Sản phẩm biên dịch và chạy được ngay trên máy khác với JDK 21 chuẩn, không phụ thuộc đường dẫn cá nhân.
  \item Đã chạy thử demo nhiều cửa sổ \code{ClientUI} kết nối đồng thời vào \code{GameServer} trên cổng 8888.
  \item Mã nguồn được quản lý trên kho \code{git} GitHub, lịch sử commit phân nhánh rõ ràng qua từng chức năng \code{F01}--\code{F21}.
  \item Có tệp \code{README.md} và thư viện kiểm thử \code{lib/junit-platform-console-standalone.jar} đi kèm để chạy lại ngay.
  \item Mọi hình vẽ, bảng biểu, mã nguồn và giải thuật đều có chú thích, có nhãn và được tham chiếu trong thân bài.
  \item Toàn bộ 5 mục tiêu ở Chương~\ref{ch:modau} đều được đối chiếu và xác nhận kết quả ở Chương~\ref{ch:ketqua} và Chương~\ref{ch:ketluan}.
  \item Mọi con số trong báo cáo (21/21 chức năng, 25 lớp kiểm thử, 103/103 ca kiểm thử thành công) trùng khớp 100\% với kết quả chạy thật.
  \item Mọi tài liệu trong \code{refs.bib} đều được trích dẫn trong bài và tuân thủ đúng phạm vi kỹ thuật Chương 1--6 của học phần.
  \item Đã khai báo minh bạch phần sử dụng công cụ trí tuệ nhân tạo hỗ trợ và cả hai thành viên đều nắm vững từng dòng mã nguồn.
  \item Đã xoá toàn bộ hộp gợi ý, khối nội dung mẫu và chương sổ tra cứu quy cách trước khi xuất bản chính thức.
\end{tukiem}
